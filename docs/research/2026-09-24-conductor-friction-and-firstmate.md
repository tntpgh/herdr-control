## Firstmate study

Read-only study of `kunchenguid/firstmate`, commit `b42d4fa8a752fad9a5f0235783b02534bce29219`, retrieved 2026-09-24. README and source were read; install scripts and code were not run. Full cited brief: `tmp/firstmate-study-summary.md` (generated from `tmp/firstmate-study-brief.md`).

### What it is

Firstmate is an “agent distro”: a primary agent (“first mate”) spawns autonomous coding workers into visible tmux/herdr/zellij/orca/cmux sessions, gives each a clean treehouse worktree, supervises status, and returns PRs or reports. It is primarily shell with TypeScript/JavaScript harness adapters. GitHub metadata on the retrieval date: 7,144 stars, MIT, 0 releases/tags, created 2026-06-12, pushed 2026-09-24, approximately 755 commits, 82 contributors, and one dominant maintainer. These metadata claims came from the GitHub API; source claims below use commit-pinned links.

### Relevant design

- Spawning is centralized in `bin/fm-spawn.sh`; worktree isolation is asserted. Sources: [README](https://github.com/kunchenguid/firstmate/blob/b42d4fa8a752fad9a5f0235783b02534bce29219/README.md#L27-L50), [architecture](https://github.com/kunchenguid/firstmate/blob/b42d4fa8a752fad9a5f0235783b02534bce29219/docs/architecture.md#L246-L287).
- Workers run with approvals bypassed/yolo by default: Claude skip-permissions/auto, Codex `--dangerously-bypass-approvals-and-sandbox`, omp `--auto-approve`, OpenCode allow-all. Sources: [fm-spawn](https://github.com/kunchenguid/firstmate/blob/b42d4fa8a752fad9a5f0235783b02534bce29219/bin/fm-spawn.sh#L301-L307), [omp adapter](https://github.com/kunchenguid/firstmate/blob/b42d4fa8a752fad9a5f0235783b02534bce29219/.agents/skills/harness-adapters/references/harness/omp.md#L22), [Codex/OpenCode](https://github.com/kunchenguid/firstmate/blob/b42d4fa8a752fad9a5f0235783b02534bce29219/bin/fm-spawn.sh#L1962-L1967).
- State detection prefers hooks and native events. Herdr uses `pane.agent_status_changed`; `blocked` is actionable, `working` clears dedupe, `idle/done` defer, and unknown falls back to polling. Sources: [transition table](https://github.com/kunchenguid/firstmate/blob/b42d4fa8a752fad9a5f0235783b02534bce29219/bin/fm-transition-lib.sh#L70-L103), [herdr eventwait](https://github.com/kunchenguid/firstmate/blob/b42d4fa8a752fad9a5f0235783b02534bce29219/bin/backends/herdr-eventwait.py#L1-L32).
- Worker messages go to a durable inbox; the terminal receives a constant doorbell. Control uses an allowlisted verb plane (`interrupt|exit|relaunch`), not arbitrary raw text. Sources: [send](https://github.com/kunchenguid/firstmate/blob/b42d4fa8a752fad9a5f0235783b02534bce29219/bin/fm-send.sh#L1-L30), [control](https://github.com/kunchenguid/firstmate/blob/b42d4fa8a752fad9a5f0235783b02534bce29219/docs/agent-control.md#L1-L19).
- Its watcher is hook/extension-owned, with a durable wake queue and generation-bound acknowledgement, not a foreground model tool call. Sources: [architecture](https://github.com/kunchenguid/firstmate/blob/b42d4fa8a752fad9a5f0235783b02534bce29219/docs/architecture.md#L9-L12), [omp supervision](https://github.com/kunchenguid/firstmate/blob/b42d4fa8a752fad9a5f0235783b02534bce29219/docs/supervision-protocols/omp.md#L10-L24).
- Audit is append-only per-task status plus an optional five-event fleet ledger, not per-tool approval records. Source: [fleet ledger](https://github.com/kunchenguid/firstmate/blob/b42d4fa8a752fad9a5f0235783b02534bce29219/docs/fleet-ledger.md#L1-L40).
- Secrets are local gitignored files/environment filtering; it has no 1Password integration and explicitly says its allowlist is not a sandbox. Source: [configuration](https://github.com/kunchenguid/firstmate/blob/b42d4fa8a752fad9a5f0235783b02534bce29219/docs/configuration.md#L406-L499).

### Gaps, migration cost, verdict

Firstmate lacks our human-only command list, per-approval decided/attempted/confirmed audit, SQLite run/task registry, formserve decisions with expiry semantics, Slack bridge, and non-Claude posture floor. It does provide worktrees, but uses flat per-task files and a markdown backlog rather than transactional SQLite. Sources: [state/backlog](https://github.com/kunchenguid/firstmate/blob/b42d4fa8a752fad9a5f0235783b02534bce29219/AGENTS.md#L95-L127), [ask-user authority](https://github.com/kunchenguid/firstmate/blob/b42d4fa8a752fad9a5f0235783b02534bce29219/.agents/skills/ask-user-authority/SKILL.md#L15-L36).

Wholesale adoption would replace `spawn-task.sh`, `run-registry.sh`, `herdr-select.sh`, Slack/formserve paths, and our posture/audit policy. It would also remove per-command gating because omp workers run yolo. That is a control-plane rewrite measured in weeks, plus loss of controls we depend on. **Verdict: borrow specific ideas, do not adopt.** Borrow native herdr status events plus one transition table; command-position tokenization; durable inbox/control verbs; hook-owned watchers; generation-bound wake acknowledgement; and pre-tool protection against unregistered delegation. Ignore its yolo permission posture, markdown backlog replacement, and mega-contract style.
